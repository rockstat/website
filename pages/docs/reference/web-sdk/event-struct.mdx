Каждое событие уходит на сервер POST-запросом на `https://<server><pathPrefix>/<urlMark>/t4k.json`
с телом в JSON. Блоки `page`, `sess`, `user`, `char`, `browser`, `lib` одинаковы для всех событий,
`data` зависит от события, `perf` и `scroll` добавляются не ко всем.

(`b` — beacon, `f` — fetch). Подробнее в разделе [Транспорт](/docs/reference/web-sdk/transport).

## Блоки сообщения

| Блок | Содержимое |
|---|---|
| `name`, `data` | Имя события и его данные. Список автоматических событий и их `data` — в разделе [Автоматические события](/docs/reference/web-sdk/auto-track) |
| `projectId` | Идентификатор проекта из конфигурации или хеш домена |
| `uid` | Идентификатор посетителя. Хранится в cookie и localStorage |
| `user` | `id` и трейты из `identify`; `ga4ClientId` и `ymId` из автоматических синхронизаций с GA4 и Яндекс Метрикой; `ts`, `tz`, `tzo` — время и часовой пояс клиента; `td` — расхождение часов с сервером |
| `page` | `url`, `path`, `query` (разобранная строка запроса, включая UTM, `gclid`, `yclid`), `ref`, `title`, `domain`, `scheme` |
| `sess` | Сессия: номер, старт, счётчики, тип источника, метки. Подробнее в разделе [Сессии](/docs/reference/web-sdk/sessions) |
| `char` | Возможности браузера: `ls` localStorage, `ae` addEventListener, `pr` Promise, `sb` sendBeacon, `ab` atob, `wp` web push |
| `browser` | `w`/`h` — область просмотра, `tw`/`th` — экран, `aw`/`ah` — доступная область, `sopr` — devicePixelRatio × 1000, `soa`/`sot` — ориентация, `if1`/`if2` — признаки iframe, `plt`/`prd` — платформа и движок, `uad` — Client Hints, `nc` — сеть, `ne` — ядра, память и квота хранилища, `nb` — батарея |
| `perf` | Navigation Timing: `cs` connectStart, `ce` connectEnd, `scs` secureConnectionStart, `rqs` requestStart, `rss`/`rse` responseStart/End, `dl` domLoading, `di` domInteractive, `dc` domComplete. Только у `page` и `page_loaded` |
| `scroll` | `dh` — высота документа, `ch` — высота области просмотра, `to` — смещение сверху, `cs` — текущая прокрутка в процентах, `ms` — максимальная прокрутка на странице. У всех событий, кроме `session`, `page`, `page_loaded`, `user_params`, `rec_start`, `rec_batch` |
| `lib` | `id`, `v` — версия библиотеки числом `major × 1e6 + minor × 1e3 + patch`, `sv` — версия сниппета, `st` — время старта библиотеки |

<Info>
  Значения в `browser.uad`, `browser.nc`, `browser.ne.sq`/`su` и `browser.nb` собираются асинхронно
  и могут отсутствовать в первых сообщениях страницы. Отсутствующие оценки батареи передаются как `-1`.
</Info>

## Полная схема событий

Точками в ключах помечен переход на следующий уровень вложенности: `page.title` означает
`{ page: { title } }`. Тип `{[string]:string}` — обычный объект со строковыми ключами и значениями.
Колонка JavaScript описывает то, что отправляет браузер; поля без неё добавляет сервер.
