Rockstat — платформа веб- и продуктовой аналитики, которую вы разворачиваете на своём сервере.
События с сайтов и приложений попадают в вашу базу ClickHouse, сырые данные остаются у вас
и доступны для любых запросов. Поверх данных работает панель аналитики: обзор проекта, сессии
с лентой событий, воронки, пути пользователей, запись сессий, Web Vitals и AI-ассистент.
Платформа расширяется собственными сервисами: любое событие можно обогатить, обработать
или отправить во внешнюю систему.

![Обзор проекта в панели Rockstat](/static/images/docs/ui/overview.jpg)

## Как это работает

1. **Web-SDK** на страницах сайта собирает просмотры, клики, взаимодействия с формами, активность,
   метрики Web Vitals, а по запросу пишет сессию для воспроизведения. Мобильные приложения
   и серверы отправляют данные через HTTP, пиксель или вебхуки.
2. **Front** принимает запросы, присваивает каждому событию ключ маршрутизации и прогоняет его
   через обогатители: определение региона по IP, разбор User-Agent.
3. **chwriter** записывает события в ClickHouse. Структура таблиц описана в конфигурации,
   свои поля добавляются без правки кода.
4. **Панель Rockstat** читает из ClickHouse узкие таблицы, которые заполняются материализованными
   представлениями, поэтому отчёты строятся быстро даже на миллионах событий в сутки.
   Сырые данные при этом доступны напрямую: SQL, Grafana, Jupyter.

## Панель аналитики

Панель открывается по адресу `https://<ваш домен>:2083/ui` и защищена паролем, заданным при
установке. Слева — разделы, сверху — общие для всех разделов настройки: период и шаг группировки,
учёт ботов, фильтры по любому измерению, кнопка AI-ассистента. Период и фильтры хранятся
в адресе страницы, поэтому любой отчёт можно отправить ссылкой.

<Tip>
  Переключатель `secret` подменяет домены, пути и IP-адреса на вымышленные, но стабильные.
  Так панель можно показывать на демонстрациях и скриншотах, не раскрывая сайт. Все снимки
  на этой странице сделаны в этом режиме, поэтому адреса, названия и цифры на них размыты.
</Tip>

### Обзор

Ключевые метрики за период с изменением к предыдущему: пользователи, сессии, просмотры,
отказы, длительность сессии и глубина. Ниже график и разбивки по страницам, источникам трафика,
UTM-меткам, географии, устройствам, браузерам и локалям. Клик по строке добавляет её в фильтр.

### Дашборды

Несколько именованных дашбордов на проект, каждый — сетка виджетов, которые можно двигать
и растягивать. Типы виджетов: число со спарклайном, график метрики во времени с разбивкой
по измерению, доля в виде кольца, таблица топ-значений и сохранённая воронка. У каждого виджета
могут быть свои фильтры поверх общих. Стартовый набор создаётся одной кнопкой.

![Дашборд с виджетами](/static/images/docs/ui/dashboards.jpg)

### Сессии

Список сессий за период: время, город, устройство и браузер, тип источника, первая страница,
количество страниц и событий, длительность. Сессия разворачивается в ленту событий с задержками
относительно начала и свойствами каждого события. Если сессия записана, рядом появляется кнопка
воспроизведения.

![Список сессий с развёрнутой лентой событий](/static/images/docs/ui/sessions.jpg)

### События

Все события проекта с количеством пользователей и срабатываний. До восьми событий можно вывести
на один график и сравнить динамику. Ниже — лента последних событий со свойствами, из неё
открывается профиль пользователя.

![Раздел событий](/static/images/docs/ui/events.jpg)

### Воронки

Шаги задаются именами событий, для просмотров страниц — путём, для остальных событий —
значением свойства. Выбирается окно между первым и последним шагом и способ подсчёта:
по пользователям или по сессиям. Воронка считается ClickHouse прямо по событиям с учётом
периода и фильтров, сохранённые воронки доступны всем.

![Воронка от просмотра главной до успешной регистрации](/static/images/docs/ui/funnels.jpg)

### Пути

Диаграмма переходов между страницами или событиями внутри сессии: от двух до восьми шагов,
стартовая страница по выбору, редкие значения сворачиваются в «Other», выход из сессии
показан отдельным узлом.

![Пути пользователей по событиям](/static/images/docs/ui/journeys.jpg)

### Запись сессий

Web-SDK записывает действия на странице через rrweb, панель воспроизводит их в плеере
с перемоткой и пропуском бездействия. Поля ввода маскируются ещё в браузере посетителя.
Записи ищутся по адресу страницы, идентификатору пользователя или устройства.

![Воспроизведение записанной сессии](/static/images/docs/ui/replay.jpg)

### Производительность

Web Vitals, собранные Web-SDK с реальных посетителей: LCP, CLS, INP, FCP и TTFB. Для каждой метрики
показаны 75-й перцентиль, распределение по зонам и динамика, ниже разбивка по страницам, хостам,
устройствам, браузерам, ОС и странам.

![Карточки Web Vitals](/static/images/docs/ui/performance.jpg)

### AI-ассистент

Кнопка «Ask AI» открывает чат, который отвечает на вопросы о текущем проекте, периоде и фильтрах:
«сколько вчера было пользователей из Бангладеш», «какие страницы входа дают больше всего отказов».
Ассистент сам выполняет запросы к данным, показывает их вместе с ответом и даёт ссылки на нужные
экраны. История разговора хранится только в браузере.

![Диалог с AI-ассистентом: отчёт по партнёрскому трафику из Казахстана с замаскированными цифрами](/static/images/docs/ui/ai-report.jpg)
